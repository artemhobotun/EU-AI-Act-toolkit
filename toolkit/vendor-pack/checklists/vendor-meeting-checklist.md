# Vendor Meeting Checklist

## Before meeting

- define use case
- list data involved
- identify affected users
- prepare questions
- invite privacy/security owner if needed

## During meeting

- ask about AI features
- ask about training data
- ask about logs
- ask about human oversight
- ask about documentation

## After meeting

- update risk register
- request missing documents
- decide next step
